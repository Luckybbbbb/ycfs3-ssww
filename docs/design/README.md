## 已锁定的设计决策（2026-10-16 与需求方逐项核对）

| # | 决策项 | 结论 |
|---|---|---|
| D1 | 技术路线 | 纯 HTML5 Canvas 2D，**不使用 Godot**；序列帧 PNG 直接 `drawImage` 迁移 |
| D2 | 部署形态 | 单机静态页为主，`api.js` 预留后端接口签名；本地存档走 localStorage |
| D3 | 目标屏幕 | 手机竖屏 9:16 优先，逻辑分辨率 720×1280；触屏/鼠标双支持 |
| D4 | 三消操作 | 交换式经典三消（相邻交换，横竖 ≥3 消除），无效交换回弹 |
| D5 | 技能元素 | 全套金木水火土重新设计包装；**行为内核**复用 roguelike 已验证技能类型（子弹/光环/锁链/脉冲/召唤/区域/束缚） |
| D6 | 技能获取 | 4 装配槽；技能随等级解锁进技能库，玩家自由装配 |
| D7 | 初始形态 | 每行初始 = 单体子弹 + 元素自带能力（火灼烧/水减速/木吸血/金穿透/土护盾） |
| D8 | 次数限制 | 无独立生成限制，消除即资源（档位充能 + CD 门控） |
| D9 | 消除强度 | 消除数量越多技能越强（档位 1~5，见 02/03 文档） |
| D10 | 特殊件 | 不做棋盘炸弹/彩虹球；四连/五连生成**一次性消耗品道具**（回血/无敌/CD 加速），棋盘内点击即用 |
| D11 | 战斗交互 | 上半区全自动放置，玩家只玩三消区 |
| D12 | 失败条件 | 主角 HP 归零 = 本关失败；三消区无独立失败态 |
| D13 | 养成 | 等级单线自动成长，等级/进度跨局持久化 |
| D14 | 关卡结构 | 每关固定 10 波，第 10 波就是关底 Boss 波；顺序解锁，已通关可重打刷级 |

## 数值纪律

- 所有数值公式冻结前必须有可机械复算的数字例，最低覆盖 `docs/standards/TDD_Standard.md` 第 5 节第 14 条：三消 3/4/5/6 连各一例、相邻等级升级曲线、技能对敌击杀边界。
- 数值改动只允许改表格与数字例同步改动，禁止只改公式不改例。
- 复用公式来源标注参考项目文件路径（如 `godot-roguelike scripts/data/constants.gd:208-220`），便于回归核对。
