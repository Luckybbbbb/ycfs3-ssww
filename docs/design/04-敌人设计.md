## 2. 行为模式（对标 roguelike 远程弹幕敌人）

- 生成于战斗区右缘屏外，向左移动至**停位 x=560**（距主角 450px）后停下。
- 停下后按攻击间隔向主角发**扇形弹幕**；主角技能弹为直线弹。
- 移动/攻击参数见第 3 节公式；竖屏战斗区（高 448、宽 720）的适配项：

| 参数 | roguelike 原值 | 本项目取值 | 说明 |
|---|---|---|---|
| 敌人开火射程 | 600 | 500 | 按战斗区宽 720/原横屏 1280 ≈ 0.56 缩放取整，保证停位在屏内 |
| 停位（engage 距离） | 进射程即停 | 450px | 停位 x = 主角 x(110) + 450 = **560**，弹道可视 |
| 主角判定半径 | — | 40 | 圆形碰撞 |

### 2.1 队列堆叠与攻击门控（v0.2 增补，需求方 2026-10-16）

- **只沿 X 轴排队，不纵向堆叠**：同屏敌人按「最接近主角者在前」排队，中心距 ≥ **110px**（`MIN_QUEUE_GAP`，草案值，宽体类型允许贴邻，M5 校准）；前排停位于 x=560，后续依次 +110。
- **慢慢靠近，进射程才攻击**：敌人以 SPD(w) 慢速逼近自己的队列槽位；只有与主角距离 ≤ 开火射程 500 时才累计攻击计时，超出射程时计时钳制在 `interval × 0.5`（对标 roguelike `enemy.gd` 超距钳制，进射程后可快速首发）。前排（450px）在射程内，后排（≥560px）只排队不开火。
- **前排死亡后队列前移**：幸存者槽位立即重排（front 补位到 560），逐个慢速前移。
- **攻击动画（资源映射口径）**：敌人开火时本类序列帧按 **2×fps 单次正播**（时长 = 帧数/(2×fps)），其余时间按原 fps 循环待机；主角释放技能时播放 `walk_start` 3 帧（16.7fps 单次，对标 player.tscn startup），战斗待机 = `idle` 8fps 循环。资源集无独立攻击帧，此为映射约定。

## 3. 数值公式（复用，w = w_global）

```
HP(w)     = 30 × hp_mult × (1 + (w−1) × 0.12)        # 精英 ×2（预留）
DMG(w)    = 8 × dmg_mult × (1 + (w−1) × 0.10)
SPD(w)    = 150 × (1 + (w−1) × 0.03)      px/s（左移）
攻速间隔(w) = max(1.2, 2.0 − (w−1) × 0.04)  s
弹幕伤害   = DMG(w) × 0.5
弹数(w)    = 1 + ⌊(w−1) / 3⌋
扇形角(w)  = 15° + 弹数 × 5°
弹速(w)    = 300 + 5 × w        px/s
```

## 4. 波次编排（FR-4）

```
w_global = (L − 1) × 10 + w_local        # L=关卡号(1 起)，w_local=1..10
每波敌人数 = 4 + 2 × w_local             # Boss 波除外：Boss×1 + 护卫×2
潮汐刷怪：潮数 = ceil(敌数/5)，每潮 3~5 只、末潮可为 1~5 只，同屏 ≤5 只
  拆分例：第 1 波 6=3+3；第 2 波 8=4+4；第 9 波 22=5+5+4+4+4
第 10 波：Boss + 2 只护卫（本关权重最高的小怪，同 05 文档第 4 节）
```

## 5. 数字例（可机械复算）

### 5.1 普通怪

第 1 关第 1 波（w=1）slime：HP = 30×1.0×1 = **30**；DMG = 8×1.0×1 = **8**（弹幕 4）；弹数 = 1；间隔 = 2.0s；SPD = 150。

第 3 关第 5 波（w=25）snake：HP = 30×1.6×(1+24×0.12) = 48×3.88 = **186**（取整 186.24→186）；DMG = 8×1.4×(1+2.4) = 11.2×3.4 = **38**（弹幕 19）；弹数 = 1+⌊24/3⌋ = **9**；扇形角 = 15+9×5 = **60°**；弹速 = 300+125 = **425**；间隔 = max(1.2, 2.0−0.96) = **1.2s**。

### 5.2 Boss（每关第 10 波）

第 1 关 Boss（w=10，boss 倍率 3.0/2.5）：
- HP = 30×3.0×(1+9×0.12) = 90×2.08 = **187**（187.2 取整）
- DMG = 8×2.5×(1+9×0.10) = 20×1.9 = **38**（弹幕 19）
- 弹数 = 1+⌊9/3⌋ = **4**；扇形角 = 15+4×5 = **35°**；弹速 = 350；间隔 = max(1.2, 1.64) = **1.64s**

第 5 关 Boss（w=50）：HP = 90×(1+49×0.12) = 90×6.88 = **619**；DMG = 20×(1+4.9) = **118**（弹幕 59）；弹数 = 1+⌊49/3⌋ = **17**；扇形角 = 100°；弹速 = 550。

### 5.3 击杀边界（直接伤害口径，与 03 文档 4.6 完整口径互验）

- Lv10 主角（ATK 19）tier5 火弹直接 87/发 → 第 1 关 Boss HP 187：2 发 174 不足、3 发 261 足 → 直接伤害 **3 发**；含灼烧完整口径为 2 发（第 2 发于 t=2.75 命中时击杀，含 2 次跳伤，见 03 文档 4.6 时间线表）。
- Lv20 主角（ATK 29）tier1 金弹 = 29×1.0×1.3 = 37.7→38 → 第 1 关 Boss：187/38 = 4.92 → **5 发**（金弹无持续伤害，直接口径即完整口径）。
