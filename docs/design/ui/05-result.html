  • 横幅缓慢淡入下沉（不弹跳——失败不庆祝），音效下行两音（A3→E3）低沉短促，时长 <0.8s 快速给「再战」路径

  • 同样支持点按跳过；失败态建议不循环播放音效

Canvas 实装映射要点

  • 时间轴用 resultT（结算秒表）驱动：横幅 scale=overshoot 曲线、行 alpha/x=分段线性；跳过=把 resultT 直接推到末值
  • 彩带=屏幕空间粒子（120 粒上限，五行色，重力+旋转），复用 fx.js 粒子池
  • 数字滚动=显示值向目标值指数逼近（8/s），到账帧触发一次 tick 音
  • 音效走 sfx 模块新增 resultWin() / resultLose()（WebAudio 合成，不受 BGM 开关影响、受音效开关门控）
